# Исправления по аудиту 07.11.2026 и Песочница: покупательское 1.19, кабинеты 1.7

Аудит: в папке проекта `argeda/prilozhenie/audit-vseh-prilozheniy-2026-11-07.md`. Артак сказал «Да» 07.11.2026.

## Новое приложение «ARGEDA Песочница» (argeda-sandbox.apk, ru.argeda.sandbox)
- Одно приложение для проверок вместо четырёх копий кабинетов. Оранжевая иконка, сверху всегда оранжевая полоса
  «ПЕСОЧНИЦА · роль · сменить роль».
- Роли: Покупатель, Продавец, Пункт выдачи, Курьер, Админ. Всё открывается только на копии сайта kopiya.argeda.ru
  (`/`, `/seller`, `/pvz`, `/courier`, `/admin`). Вход на копии общий для всех ролей — чтобы зайти другим аккаунтом,
  в меню ролей есть «Выйти из аккаунта на копии».
- Живой сайт (любой *.argeda.ru, кроме kopiya.) из Песочницы не открывается ни внутри, ни в браузере.
- Уведомлений о заказах в Песочнице нет. Камера, геолокация, сохранение файлов, пароль копии — как в кабинетах.
- Старые копии кабинетов (`ru.argeda.*.kopiya`, до 1.6) больше не собираются и не обновляются — их можно удалить с телефона.

## Кабинеты 1.7 (код 8)
- Сервер не отвечает, а интернет у телефона есть — экран «Сервер ARGEDA временно недоступен» с телефоном магазина
  вместо «Проверьте интернет». Страницы-заглушки хостинга (502/503/504) заменяются этим экраном. Пока экран открыт,
  кабинет сам пробует открыться раз в 30 секунд.
- Внутри кабинета открываются только argeda.ru, www., seller., pvz., courier., admin. Остальные поддомены
  (crm., ai., world., estate.) — в браузере, без доступа к мосту приложения.
- Текст ошибки обновления больше не отправляет на argeda.ru/app.

## Покупательское 1.19 (код 20)
- Плашка и сообщения различают «Нет интернета» и «Сервер ARGEDA временно недоступен» (со ссылкой на звонок в подсказке).
- «Выйти из профиля» стирает с телефона заказы и записи с сайта, имя, почту, телефон, адрес доставки.
  При входе другим аккаунтом сохранённые заказы прошлого аккаунта не показываются.
- Время записи на ремонт выводится через экранирование.
