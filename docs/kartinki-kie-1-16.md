# Картинки из Kie: покупательское 1.16 и кабинеты 1.5 (03.11.2026)

Картинки сгенерированы в Kie (модель google/nano-banana), исходники и скрипт — в папке проекта `argeda/dizayn/kie/`,
макеты с текстом — в Figma, страница «Kie — картинки 03.11».

Покупательское 1.16 (код 17):
- баннер «Самовывоз» получил фото (`assets/img/banners/pickup.jpg`), раньше был просто синий фон;
- новый баннер «Продавайте на ARGEDA» (`sellers.jpg`) открывает seller.argeda.ru в браузере.

Кабинеты 1.5 (код 6): у каждого кабинета своя иконка — магазин (Продавец), посылка с меткой (Пункт),
сумка курьера (Курьер), шестерёнка со щитом (Админ). Файлы `app/src/<кабинет>/res/drawable-nodpi/ic_art.png`,
фон `drawable/ic_bg.xml`, сама иконка `mipmap-anydpi-v26/ic_launcher.xml`. Монохромная иконка (Android 13+) — общий логотип.

Покупательское 1.17 (код 18): номер версии в «Настройках» берётся из самого APK — в 1.16 там по ошибке оставалось «1.15».
Также в 1.17: при первом запуске новой версии сбрасывается кэш WebView (иначе мог показываться старый вид), а баннеры «Самовывоз» и «Продавцам» стоят первыми.
