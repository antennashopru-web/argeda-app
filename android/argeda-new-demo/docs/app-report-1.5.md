# ARGEDA 1.5 — что нового и отчёт о проверке

Дата: 24 октября 2026. Сборка: versionName 1.5, versionCode 6 (отладочная для эмулятора).

## Что сделано в этой версии

### 1. Фильтры и сортировка — теперь и в поиске
Фильтры (цена, «есть сегодня») и сортировка (Популярные / Дешевле / Дороже / Новинки) уже
работали в разделах каталога. В этой версии те же чипы добавлены **на экран поиска** — как на
ВБ/Озон: над результатами поиска строка «Фильтры · Популярные · Дешевле · Дороже · Новинки».
Всё считает сервер (проверено на живом API: `price_min/price_max`, `in_stock=1`, `sort=`).

### 2. Рейтинг звёздами и отзывы
- Оценка теперь рисуется **иконками-звёздами** с дробным заполнением (было текстовое ★★★★★).
- В карточке товара — блок **«Отзывы»**: крупная оценка, разбивка по звёздам (5/4/3/2/1),
  список отзывов с аватаром, именем, датой и текстом, кнопка «Показать все».
- Звёзды и оценка появились и в карточках каталога/поиска/лент.

**Важно:** сервер пока не отдаёт оценки и отзывы. Чтобы не показывать покупателям выдуманное,
в **боевой** сборке рейтинга нет (вместо него «Оценок пока нет»). А в **тестовой** сборке —
демо-оценки с пометкой «демо», чтобы вы видели готовую вёрстку. Как только сервер пришлёт
настоящие `rating` и список отзывов — всё включится само, без переделки.

### 3. Мелкие правки из прошлого шага
- Нижнее меню: активная вкладка — бирюзово-синий градиент, белая иконка/подпись.
- Заказ: линия статуса и QR-карточка следуют статусу заказа (не рассинхронизируются с шапкой).

### Найдено и исправлено по ходу прогона
- В карточке демо-оценка иногда показывала **отрицательное число отзывов** («4,4 · -197») —
  из-за знакового сдвига в хеше. Поправил (стало 5–243, без минусов).
- Три демо-отзыва выходили одинаковым текстом — развёл по разным.

## Что отправлено на сторону сервера (в `app-api-v1.2.md`)
- `rating: {value, count}` в товаре **и** в элементах списка `/catalog/products`.
- `GET /catalog/products/{id}/reviews?page=N` — список отзывов (только подтверждённые покупатели, с модерацией).
- Для фильтра по бренду: поле `brand` в товаре, параметр `brand=`, и фасеты `facets.brand[]`/`facets.price` в ответе списка.
- Плюс из прошлого шага: при статусе «готов» обновлять шаги заказа и выдавать `pickup_code` для QR.
